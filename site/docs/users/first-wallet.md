# Your first wallet

The first screen offers **Create a new wallet** and **Restore from phrase**. To bring in a wallet
you already have, see [Restore](restore.md).

## On the desktop

1. Choose **Create a new wallet**.
2. Choose a **password**. It unlocks the wallet on this computer and is asked for every send.
   New wallets need at least 8 characters.
3. **Reveal phrase** and write the words on paper, in order. Make sure nobody can see the screen.
4. Confirm that you have written down all 24 words.

Epic Cash Desktop can hold several wallets: **Add a wallet** on the unlock screen, or
**Settings › All wallets**.

The first screen also picks the app data folder. The folder can be changed only before the first
wallet is added.

## On the phone

1. Choose **Create a new wallet**.
2. Choose a **6-digit PIN** and enter it again.
3. Turn on fingerprint or face unlock if you like. The PIN still works.
4. Back up the recovery phrase: **Settings › Security › Back up recovery phrase**.

After three wrong PINs the app waits before it checks the next one, and longer after each further
miss.

## Then

- Write down the [recovery phrase](recovery-phrase.md) before you receive anything.
- [Receive your first EPIC](send-and-receive.md#receive).
- The wallet connects to a public node and to an Epicbox server by itself. [Nodes](nodes.md) and
  [Epicbox](epicbox.md) explain how to change them.

:::tip
A new wallet starts with one contact, BT LABS' donation address. You can delete it; it is not
added again.
:::

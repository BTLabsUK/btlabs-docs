<summary>Full help of lepic</summary>

```text
A light Epic Cash wallet

Commands that open the wallet read its password from the file LEPIC_PASSWORD_FILE names (owner-only),
else from LEPIC_PASSWORD, else from a hidden prompt, else from one line of standard input. Secrets
are never taken from arguments. LEPIC_PASSWORD stays in the process environment while the command
runs, where the same user's processes can read it; the file, the prompt and standard input do not
leave it there.

Usage: lepic [OPTIONS] <COMMAND>

Commands:
  wallet     Create, restore and inspect the wallet
  tx         Send, receive and manage transactions
  invoice    Ask for a payment, or pay one asked for, over Epicbox or through slate files
  epicbox    Exchange slates through an Epicbox relay
  http       Take payments sent straight to this wallet over HTTP
  tor        Take payments at the wallet's onion address over Tor
  node       Query the node
  contact    Pair with contacts, and exchange invoices and slates with them through their mailboxes
  in-person  Ask for or make a payment face to face, through a code scanned once
  epic1      Take payments at an epic1 address through links, and pay epic1 links
  mailbox    List, add, remove and test the mailboxes native mail goes to
  epictx     Look into .epictx files
  proof      Export and verify payment proofs of payments to an epic1 address
  profile    Show or change what this wallet tells its paired contacts about the host
  serve      Hold the wallet open and answer the wallet API on a local socket
  api        Choose who may use the wallet API from another machine
  shell      Open the interactive shell, which `lepic` without a command opens at a terminal

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Exit codes:
   0  success
   1  internal: an unexpected failure, see the log
   2  usage: invalid arguments or missing input
   3  config: invalid settings or config file
   4  wrong_password: the password did not unlock the wallet
   5  wallet_state: no wallet, a wallet already exists, it is in use, or it belongs elsewhere
   6  not_found: no such transaction, slate or account
   7  rejected: the slate or request was refused; nothing was stored
   8  insufficient_funds: not enough spendable funds
   9  node: the node could not be reached or answered badly
  10  transport: the slate file, the mailbox or the http listener failed, or a mailbox failed its probe
  11  incomplete: stored, but not delivered or not posted; retry
  12  interrupted: stopped before it finished
  13  slate_too_large: the slate holds more inputs and outputs than the mailbox takes; nothing was stored
  14  no_shared_mailbox: the wallet's mailboxes hold none the payee reads; nothing was sent
  15  not_delivered: the payment is stored, but no mailbox took it yet; the outbox keeps trying
  16  earlier_address: an epic1 address or link of an earlier release, which this version cannot read
```

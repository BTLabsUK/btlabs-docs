# Security policy

## Reporting a vulnerability

Do not open a public issue. Email **support@btlabs.uk**.

This repository is the documentation site. A vulnerability in the wallets belongs to
[wallet-for-epic](https://github.com/BTLabsUK/wallet-for-epic),
[LEPIC](https://github.com/BTLabsUK/lepic) or
[lepic-flutter](https://github.com/BTLabsUK/lepic-flutter); report it the same way. For the
site itself: anything that serves wrong instructions about recovery phrases, keys or downloads, or
any script or link a visitor did not expect.

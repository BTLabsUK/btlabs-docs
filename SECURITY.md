# Security policy

## Reporting a vulnerability

Do not open a public issue. Email **support@btlabs.uk**, or open a *confidential* issue on GitLab
(New issue, then tick "Turn on confidentiality"); only the maintainers can see it.

This repository is the documentation site. A vulnerability in the wallets belongs to
[wallet-for-epic](https://gitlab.com/bt-labs-group/wallet-for-epic),
[LEPIC](https://gitlab.com/bt-labs-group/lepic) or
[lepic-flutter](https://gitlab.com/bt-labs-group/lepic-flutter); report it the same way. For the
site itself: anything that serves wrong instructions about recovery phrases, keys or downloads, or
any script or link a visitor did not expect.
